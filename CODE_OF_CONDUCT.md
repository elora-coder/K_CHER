# Code of Conduct

## Наші правила

Учасники проєкту повинні ставитися один до одного з повагою та створювати комфортне середовище для спільної роботи.

Ми очікуємо від усіх учасників:

- поважного ставлення до інших учасників;
- конструктивного спілкування;
- коректного проведення code review;
- відсутності образ та переслідувань;
- зосередженості на покращенні проєкту.

## Неприйнятна поведінка

До неприйнятної поведінки належать образи, погрози, переслідування, дискримінаційні висловлювання та навмисне перешкоджання роботі інших учасників.

## Повідомлення про порушення

Про проблему можна повідомити відповідальному учаснику проєкту приватним способом.

## Застосування правил

Учасники, які порушують ці правила, можуть отримати попередження або обмеження доступу до участі в проєкті.
