# Security Policy

## Повідомлення про вразливості

Якщо ви знайшли потенційну вразливість у проєкті, не створюйте публічний Issue з деталями проблеми.

Повідомте про проблему відповідальному учаснику проєкту приватним способом.

## Що потрібно вказати

За можливості додайте:

- опис вразливості;
- кроки для її відтворення;
- можливі наслідки;
- інформацію про середовище, у якому виникла проблема;
- можливий спосіб її виправлення.

## Обробка повідомлень

Повідомлення буде розглянуто, після чого буде визначено необхідні дії для усунення проблеми.

Після виправлення вразливості відповідна інформація може бути додана до CHANGELOG.
