# Support

Якщо у вас виникли питання щодо використання проєкту або його налаштування:

1. Перевірте README.md.
2. Перегляньте наявні Issues.
3. Якщо відповідь не знайдена, створіть новий Issue з детальним описом проблеми.

У повідомленні бажано вказати:

- що саме не працює;
- кроки для відтворення проблеми;
- очікуваний результат;
- фактичний результат;
- повідомлення про помилку, якщо воно є.

Для пропозицій щодо покращення проєкту можна створити окремий Issue.
